# FindAll: полная повторная проверка, 12 октября 2026

Проверка выполнена на Windows в текущем проекте. Основные сценарии прошли;
доступность внешних источников остаётся частичной. Рабочие базы, профиль и
сетевые настройки не изменены. Все проверки записи использовали отдельные базы
и каталоги `jobfind_out/full-check-20261012-145803`.

## Исправленные ошибки

1. **TLS и Яндекс.** Соединение использовало только первый проверенный публичный
   IP. На перенаправлении Яндекса TLS выдавал `FileNotFoundError`.
   Теперь транспорт пробует остальные проверенные адреса в пределах времени
   соединения. Проверка сертификата и имени сервера сохранена. Запрос POST
   отправляется один раз; ошибка сертификата и отклонённый CONNECT не повторяются.
   После исправления CLI и настоящий UI сообщают о CAPTCHA вместо TLS-сбоя.
2. **Зависимости SpiderFoot.** Устранён конфликт ipwhois 1.2.0 с dnspython 2.8.0.
   В requirements закреплён ipwhois 1.3.0, из setup.bat удалён обход `--no-deps`.
   Старый wheel сохранён в диагностическом каталоге. `pip check` чистый;
   настоящий загрузчик SpiderFoot успешно импортирует модуль WHOIS.
   Метаданные совместимости проверены на [PyPI](https://pypi.org/project/ipwhois/).
3. **Сохранение черновика.** При глобальных аргументах перед `draft` CLI принимал
   значение `--db` за название команды и терял выходной файл. Исправлено
   определение команды. Реальный черновик сохраняется, включая подпись;
   добавлены регрессии для обоих порядков аргументов и отсутствия файла.
4. **Web-Check screenshot на Windows.** Linux-запуск использовал `/tmp`, а запасной
   запуск передавал Chrome параметры serverless Chromium. Windows теперь
   использует Puppeteer с отдельным временным профилем и подходящими параметрами.
   В отдельном экземпляре продуктового API получен настоящий PNG: 29 219 байт.
   Проверены очистка браузера при успехе и при ошибке навигации.
5. **Выбор страниц для захвата.** URL с портом 9090 занимал единственное место
   захвата, хотя транспорт запрещает этот порт. Такие URL исключаются до выбора
   лимита. Проверено, что следующая допустимая HTTPS-страница захватывается.

`test.bat` дополнен шестью уже существовавшими автономными проверками модулей:
AI evidence, AI CLI, OSINT, public contacts, domain recon и tools catalog.
Они не отправляют сообщения и не запускают живые поисковые проверки.

## Внешние ограничения и непроверенный объём

- В последнем живом поиске Google и Brave вернули 429; Яндекс и Mojeek потребовали
  CAPTCHA. DuckDuckGo дал 9 строк, Wikipedia 10, News 9, GitHub 1. Bing и Bing RSS
  дали нулевой релевантный результат. SpiderFoot достиг лимита, сохранив 1 событие.
  Такие состояния остаются видимыми в исходном отчёте, без заявления полного охвата.
- Доменное досье сохраняет предупреждения внешних служб: crt.sh 502, Anubis 403,
  тайм-аут Amass, ограничения SSL Labs и других модулей. Эти ответы не считаются
  доказательством отсутствия информации.
- Исправленный Web-Check проверен в новом отдельном процессе. Уже работавший
  сервер на 3031 использует загруженный ранее код; для нового поведения нужен
  его обычный перезапуск. Существующий процесс принудительно не останавливался.
- Живая отправка SMTP/Telegram, платные или требующие ключей API, Tor/Apex-маршрут,
  радиоустройства, каждая сторонняя интеграция по отдельности и чистая установка
  на другом компьютере не проверялись. 2GIS проверялся автоматическими тестами и
  отклонением неверного URL; новый живой сбор 2GIS не выполнялся.
- В этой проверке не создавался инсталлятор и не выполнялся отдельный полный
  security-аудит проекта.
