# FindAll interface illustrations

Captured on 29 October 2026 using the application's existing native screenshot
mode. `workspace.png` shows the empty dossier workspace. Browser and diagram
screens use fictional Aster Research fixtures with reserved `example.invalid`
addresses. Statistics were calculated locally from 32 synthetic numeric records.

`walkthrough.gif` is an animated slideshow of these same four native screenshots,
not a live collection recording. It does not imply that a website, AI provider or
authenticated account was contacted. No screenshots from the owner's saved
investigations, profiles, credentials or desktop were used.

The images document the interface; matching nodes and statistical signals do not
establish identity, ownership or coordination. See the root README for setup and
the third-party notices for component licensing.
